# Veritaware.Toolkits.CWEL

![c++17](https://img.shields.io/badge/C%2B%2B-17-blue?logo=cplusplus)
![MIT license](https://img.shields.io/badge/license-Zlib-green)

**_C++ Wicked Extensions Library_** is a set of C++17 header-only libraries that provide various utilities and extensions
to the C++ standard library inspired by some functionalities of the .Net Framework.

The library consists of only header files to avoid the need for compilation and linking,  making it easy to
integrate into any C++ project without the additional storage and maintenance overhead of a separate library.
